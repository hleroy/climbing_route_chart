Copier-coller les infos depuis un tableur ou depuis un fichier CSV (comme dans l'exemple ci-dessous). Le seul pré-requis est que votre tableau comporte 4 colonnes obligatoires intitulées précisément : Relais Couleur Cotation Ouvreur

Une colonne optionnelle Commentaire peut être ajoutée pour afficher un commentaire en italique sous le nom de l'ouvreur (par exemple pour indiquer une consigne "Sans arrête", le nom de la voie ou la date d'ouverture).

Le fichier PDF généré comporte une page par relais. Pour les voies marbrées, suivez-bien la nomenclature dans mon exemple (cela génère un dégradé de couleur 🤩) :

MARBREE ( COULEUR1 / COULEUR2 / ... )

Liste des couleurs reconnues

Pour plus de personnalisation, je vous recommander d'éditer le fichier PDF avec le logiciel de dessin vectoriel Inkscape. Les disques sont compatibles avec les plaques de protection plexiglas de la boutique 9c+ (désormais fermée). Il doit être possible d'en commander sur mesure sur un site comme https://www.plaque-plexiglass.fr
